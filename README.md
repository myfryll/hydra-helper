# 🐍 Hydra Helper

> **Hydra Helper** — консольное приложение на Python, которое упрощает работу с **THC Hydra**.

Вместо длинных и сложных команд пользователь проходит пошаговый мастер настройки, после чего программа автоматически собирает корректную команду Hydra и запускает её.

Проект создан в учебных целях для изучения Python, разработки CLI-приложений и инструментов тестирования безопасности.

---

# ✨ Возможности

* 🔹 Пошаговый мастер настройки атаки.
* 🔹 Один логин или список логинов.
* 🔹 Один пароль или словарь паролей.
* 🔹 Настройка количества потоков.
* 🔹 Выбор пользовательского порта.
* 🔹 Поддержка режима Verbose (`-v`).
* 🔹 Остановка после первой найденной пары логин/пароль (`-f`).
* 🔹 Красивый интерфейс терминала с использованием библиотеки **Rich**.
* 🔹 Предварительный просмотр конфигурации перед запуском.

---

# 🚀 Использование

Запустите программу:

```bash
python3 main.py
```

Далее ответьте на вопросы мастера настройки.

После ввода всех параметров программа покажет итоговую конфигурацию и попросит подтвердить запуск.

---

# 📦 Требования

* Python 3
* THC Hydra
* Rich

Установка библиотеки Rich:

```bash
pip install rich
```
